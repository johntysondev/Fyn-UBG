## What is this?

**fyn ubg** is a fully self-hosted ubg.

## Features

| | |
|---|---|
| 🕹️ | **844 games** — the full gn-math library, self-hosted. Click any card and it boots in the in-app player |
| 🧭 | **Two layouts** — Sidebar rail or classic Browser chrome with tabs + address bar. Switch anytime in Settings |
| 🎲 | **Random tab** — 24 shuffled picks, click again to reshuffle |
| 🔖 | **Bookmarks** — star any game, find it under Saved |
| 🔍 | **Search everywhere** — home search, address bar, and a live filter on every catalog tab |
| 🌗 | **4 themes** — Dark, Light, Slate, Navy, each with its own accent |
| 🔤 | **3 fonts** — Clean, Mono, Serif |
| 🥷 | **Tab cloak** — disguise the tab as Quizlet, Classroom, Drive, Desmos, Canvas, or Docs |
| 😱 | **Panic key** — one keypress sends you to a safe URL (default `]` → Classroom) |
| 📏 | **Card density + motion toggles** for the school chromebooks |

## ⌨️ Shortcuts

| Key | Does what |
|---|---|
| `1` – `5` | Jump to Home / Games / Random / Saved / Settings |
| `/` | Focus search |
| `]` | Panic cloak (customizable) |
| `Esc` | Close player / clear search |
